Рабочая папка (working directory)

Индекс (staging area/index)

Коммит (commit)



Git - это локальная система контроля версий, которая отслеживает изменения в файлах.

GitHub - это сайт, где хранятся удаленные репозитории, чтобы кодом можно было делиться.



git diff - показывает изменения в рабочей директории, которые еще не добавлены в индекс.

git diff --staged - показывает изменения, которые уже добавлены в индекс, но еще не закомичены.



git status - показывает состояние рабочего дерева и индекса

git diff - выводит разницу между работающей дирректорией и индексом

git diff --staged - выводит разницу между последним комитом и индексом



Векта в Git - это указатель на определенный комит который позволяет вести отдельную линию разработки.

При создании комита ветка переместится в новый а старый комит останется в истории 

Слияние объединяет слияния из одной ветки с другой. В нашем случае ветка txplain-branches будет слита с main.
